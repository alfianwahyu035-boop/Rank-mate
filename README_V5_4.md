# RankMate V5.4 — Ranking per Area Manager

Fitur baru:
- Filter **Semua AM** atau pilih salah satu Area Manager (AM) dari data yang diimpor.
- Saat AM dipilih, ranking mingguan dimulai dari #1 dalam AM tersebut.
- Overall bulanan juga menghitung ranking setiap minggu khusus AM terpilih.
- Ekspor PNG, CSV dan Excel (termasuk OVERALL + WEEK 1–5) mengikuti pilihan AM.
- Acuan data lama 57 toko = AM Ratono. Untuk AM lain, pada menu Data Mingguan aktifkan opsi **Impor semua toko dari sumber**, lalu impor tiga file monitoring yang sesuai.

Untuk GitHub Pages, taruh `index.html` di root repository, aktifkan Pages. Untuk Netlify, unggah isi ZIP. Data tetap di browser lokal; backup JSON sebelum pembaruan.

Paket ini adalah source Android Capacitor, belum file APK final.
